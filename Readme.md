This repository contains a collection of my favorite books in **Statistics**, **Programming**, and **Data Science**. It also contains valuable technical articles. The books are categorized into four main sections; statistics books (books on general statistical methods), medical statistics (books on special statistical methods applied to medical research), R books (books on R programming language), and Python (books on Python programming language).

The growth of your skills and knowledge is majorly a function of the books you read and the articles you interact with in the course of your career.

*When action grows unprofitable, gather information; when information grows unprofitable, sleep.*
